About this rebuild

From a static 2023 hero page to a testable interaction system.

The original repository had Lorem Ipsum copy, dead navigation links, an empty JavaScript file, and a mobile menu that could not open. KINETIC keeps the repository's vanilla front-end identity while giving it a defensible engineering story.
